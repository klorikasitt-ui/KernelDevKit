
# 🚀 KernelDevKit IDE
**9KB'lık Saf Güç: Mobil Cihazlar İçin Düşük Seviyeli Geliştirici Ortamı**
KernelDevKit, Android/Termux ekosistemi için özel olarak tasarlanmış, ultra hafif (9KB) ve Python tabanlı bir **TUI (Terminal User Interface)** kod editörüdür. Özellikle kısıtlı donanımlarda işletim sistemi çekirdeği, sürücü ve sistem programlama yapan geliştiriciler için optimize edilmiştir.
## 🛠 Kurulum
Termux üzerinde saniyeler içinde kurulum yapabilirsiniz:
### 1. Depoyu Klonlayın
```bash
git clone https://github.com/klorikasitt-ui/KernelDevKit.git
cd KernelDevKit

```
### 2. Sistemi Kurun
Aşağıdaki komut bağımlılıkları yükler ve kdk komutunu /usr/bin dizinine kopyalar:
```bash
make install

```
### 3. Çalıştırın
Kurulumdan sonra terminalin her yerinden şu komutu yazmanız yeterlidir:
```bash
kdk

```
## ⌨️ Kısayol Tuşları
| Tuş | İşlev |
|---|---|
| **Ctrl + S** | Mevcut dosyayı kaydeder. |
| **Ctrl + R** | Kodunu derler ve sonuçları log panelinde gösterir. |
| **Q** | IDE'den güvenli çıkış yapar. |
